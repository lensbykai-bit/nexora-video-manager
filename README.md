# Nexora Video Manager

Android video organizer for media the user is authorized to access.

## v1 features
- Scan videos exposed through Android MediaStore
- Android 13+ READ_MEDIA_VIDEO permission support
- Pick a video through Android's system document picker
- Khmer + English interface
- No DRM/encryption bypass

## Planned
- Thumbnail/video list
- Preview player
- Multi-select
- Rename and copy/export
- Episode organization
- Share/export workflow to Nexora Dub.Ai

Open the project in Android Studio and build the `app` module.
